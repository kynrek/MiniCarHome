Open-source Android launcher

MiniCarHome

An easy-to-use, clutter-free home launcher for cars with Android “AI boxes”. Your navigation runs live in a big window, and a slim panel beside it holds the clock, weather, what’s playing and the apps you actually use in the car. No ads, promo tiles or floating buttons.

Made for the 2023 MINI Cooper

Built and tested on the MMB MAX CarPlay AI Box for BMW 2023+ (iDrive 8/8.5/9), Android 13, 8+128GB, which also works with the 2023 MINI Cooper SE. The layout adapts to other screens, but sizes and spacing were tuned for the MINI.

How it works with the MINI: the 2023 MINI Cooper supports wireless Apple CarPlay but not Android Auto. The box pairs with the car over Bluetooth, joins the car’s CarPlay Wi-Fi as if it were an iPhone, and streams its whole Android screen to the car over wireless CarPlay, while the touchscreen sends your touches back. The result is a full Android system on the car’s display, with no phone needed. With its own SIM card, the box has its own mobile data too.

Features

Everything you need while driving, nothing you don’t.

A big main window

Google Maps runs live in a window that fills everything the panel doesn’t use, and opens by itself at startup. Pick any other app instead, such as Waze.

Apps open in the main window

Tap an app and it opens where Maps was, with the panel still beside it. Home, or the main app’s own icon at the top of your shortcuts, brings Maps back, still running, so you never lose your route.

Now playing

Artwork, title, progress bar and time remaining, with previous/next track, seek back and forward (5–60 seconds) and play/pause. Works with Spotify, Podcast Addict, Audible and more.

Clock and weather

Large clock (12-hour with AM/PM, or 24-hour) and date, with current conditions and the day’s high and low from Open-Meteo when there’s room.

Your shortcuts

Add, remove and reorder the apps on the panel, plus a full app browser with search and recently used apps.

Assistant and signal

An optional voice button: say “navigate to In-N-Out” and the route starts in Waze or Maps while the map stays in view (or have it open Android’s assistant or an app you pick), and optional Wi-Fi and cell indicators show your connection.

Edge gestures

The Box Tools companion replaces the box’s floating ball: swipe in from an edge for Back, swipe up for Home, swipe up and pause for Recent apps.

Remembers everything

Every setting is saved on the box and survives reboots.

Apps open in the main window

Open another app from the panel and it takes over the main window, with the panel still beside it.

Install

MiniCarHome needs a one-time setup from a computer with ADB, because it uses Android features that ordinary apps can’t switch on themselves (freeform windows and a few permissions).

1. Turn on Developer options and Wireless debugging on the box

  1. In the box’s own Settings app, open About and tap the build number until it says you’re a developer.
  2. In More settings (stock Android Settings), open About and tap Build number until it says “You are now a developer”.
  3. Back in More settings, search for Developer options and open it.
  4. Turn on USB debugging and Wireless debugging, and allow it on your Wi-Fi network.
  5. From a computer on the same Wi-Fi, run adb connect <box IP>:5555 and accept the prompt on the box.

2. Install and set up

  1. Download both APKs above, or build them from source.
  2. Install Box Tools first, then MiniCarHome.
  3. Run the setup commands from the README.

Making MiniCarHome the home screen alone doesn’t need ADB (More settings → Apps → Default apps → Home app), but the main window and the Wireless Debug shortcut need permissions that can only be granted over ADB. The box switches Wireless debugging off when it reboots; Box Tools’ Wireless Debug icon turns it back on in one tap.

Troubleshooting tips for the MMB box are in the README too.
